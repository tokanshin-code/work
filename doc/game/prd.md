# 地块争夺 3D 试玩复刻 - 原始需求

## 项目概述

制作一个竖屏 3D 可玩广告项目，复刻“地块争夺”的核心试玩体验：玩家在 7x10 六边形格地图上扩展领地，购买地块，通过周期性三选一卡牌布置防御塔，基地与建筑按固定频率出兵，与敌方士兵和龙单位交战。试玩目标是在 80 秒倒计时内展示“占格扩张、出兵对抗、卡牌建塔、结算 CTA”的完整广告闭环。

## 基础信息

- 游戏名称：地块争夺
- 游戏类型：六边形占格 + 卡牌建塔 + 塔防对抗
- 项目类型：LayaAir 3.x 竖屏 3D 可玩广告
- 目标平台：移动端 Web playable
- 屏幕方向：竖屏，建议设计分辨率 1080x1920
- 目标用户：策略玩家、休闲玩家、碎片时间用户
- 广告时长：80 秒局内计时，末尾或胜负后出现 CTA

## 核心玩法

玩家从地图下方己方基地开始，在六边形地图上点击相邻中立地块进行扩张。占格消耗资金，资金不足时给出反馈。局内定期弹出三选一卡牌面板，游戏暂停，玩家选择一张塔或能力卡后继续。己方基地和已部署建筑按 spawnRate 周期产出单位，敌方基地从地图上方持续产出强力单位，双方沿领地和路径交战。

## 关键参数

- 地图规模：7 列 x 10 行六边形格
- 玩家基地：约坐标 (3, 8)
- 敌方基地：约坐标 (3, 1)
- 初始资金：20
- 单次占格成本：25
- time 参数：3，运行时对齐为收入或回合节奏参数
- 建筑生命值：100
- 建筑产兵频率：spawnRate = 3 秒
- 局内倒计时：80 秒
- 三选一卡牌数：CardsPerChoice = 3
- 卡牌展示间隔：CardShowInterval = 2 个节奏单位
- 选卡时暂停：PauseGameOnCard = true
- 触摸跳转：RedirectAfterTouch active = true，count = 5

## 单位与战斗

- PlayerSoldier：hp 40，speed 3，damage 5
- EnemySoldier：hp 100，speed 100，damage 100
- 双方可扩展 Pro 士兵与龙单位
- 敌方数值明显偏高，用于制造广告压迫感
- 战斗采用近距离自动攻击，单位死亡后移除
- 基地和建筑血量可作为胜负判定依据

## 地图与地块

地图包含玩家、敌方、中立、水、熔岩、虚空等地块类型。视觉颜色参考：

- 玩家地块：#82e03a
- 敌方地块：#FF3333
- 水：#3399FF
- 熔岩：#FF6600
- 中立：#c6c4c5
- 环境色：#16b5f0

## UI 与交互

- 顶部 HUD：倒计时、资金、波次/提示
- 中部：倾斜俯视 3D 六边形战场、基地、单位和建筑
- 底部：常驻 CTA 或下载按钮区域
- 卡牌层：暂停时覆盖中下部，展示三张卡牌供玩家选择
- 教程提示：开局 1 秒后出现手指或文字引导，提示点击相邻地块扩张
- 结算弹窗：胜利或失败后展示按钮和 CTA

## 广告流程

1. 场景加载后展示双方基地、六边形地图和初始提示。
2. 玩家点击相邻地块，尝试扩张领地。
3. 达到卡牌节奏时弹出三选一面板，暂停主循环。
4. 选择塔卡后在己方领地上部署建筑，继续产兵。
5. 敌方持续推进，制造高压战斗场面。
6. 倒计时结束、基地被击破或触发胜负后出现结算弹窗。
7. 点击 CTA 或达到触摸次数阈值后触发安装跳转占位逻辑。

## 视觉风格

使用 3D 低多边形、鲜明阵营色和高可读 UI。相机采用约 -60 度 X 轴俯视角，类似棋盘战场视角。六边形格以颜色区分阵营与地形，单位采用简化士兵、龙或图标化 3D 造型。广告画面重点是地块颜色扩张、兵线碰撞、卡牌选择和 CTA。

## 成功标准

- 玩家能在竖屏 3D 视角下看清 7x10 六边形地图。
- 点击可占领地块并消耗资金，地块颜色变化明显。
- 定期出现三选一卡牌，选择后可部署塔或触发能力。
- 双方基地或建筑能周期性出兵并自动交战。
- 80 秒倒计时和胜负/CTA 流程可运行。
- 触摸计数达到 5 次后调用安装跳转占位接口或展示 CTA 强提示。
