# 地块争夺 3D 试玩复刻 - 需求文档

## 1. 项目定位

本项目是 LayaAir 3.x 竖屏 3D 可玩广告，复刻“地块争夺”的核心广告体验。玩家通过点击六边形格扩张领地，周期性选择三选一卡牌部署防御塔，依靠基地与建筑出兵抵御敌方高压推进，并在 80 秒内完成试玩体验和 CTA 转化引导。

## 2. 玩法目标

- 3 秒内让玩家理解“点击相邻地块扩张”。
- 10 秒内展示第一次三选一卡牌和建塔反馈。
- 中段通过敌方高数值单位制造压力，突出策略选择价值。
- 末段通过倒计时、胜负弹窗和 CTA 引导下载。

## 3. 核心循环

观察战场 -> 点击相邻地块 -> 消耗资金占领 -> 周期性三选一卡牌 -> 部署塔/能力 -> 建筑和基地出兵 -> 单位自动交战 -> 更新资金、地块和战局 -> 胜负或倒计时结算 -> CTA。

## 4. 场景结构

- Scene3D
  - Main Camera：俯视倾斜相机，约 X = -60 度，展示完整棋盘。
  - Direction Light：主光源。
  - HexBoard：7x10 六边形格容器。
  - Bases：玩家基地和敌方基地。
  - Buildings：部署建筑容器。
  - Units：双方单位容器。
- Scene2D
  - TopHUD：计时器、资金、提示文本。
  - TutorialLayer：开局引导文字和手指提示。
  - CardChoicePanel：三选一卡牌面板，默认隐藏。
  - ResultPanel：胜负结算和 CTA，默认隐藏。
  - CTAButton：底部常驻或局末下载按钮。

## 5. 地图规则

- 地图为 7 列 x 10 行六边形棋盘。
- 玩家基地位于约 (3, 8)，敌方基地位于约 (3, 1)。
- 地块类型包括 player、enemy、neutral、water、lava、void。
- 玩家只能占领与己方领地相邻的 neutral 地块。
- 占领消耗 hexCost = 25。
- 初始 money = 20，因此开局需要提供一次免费引导占格或快速收入，避免首击无反馈。
- 地块颜色：玩家 #82e03a，敌方 #FF3333，水 #3399FF，熔岩 #FF6600，中立 #c6c4c5。

## 6. 经济与时间

- TimerCount = 80 秒，倒计时显示在顶部。
- money 初始值为 20。
- hexCost = 25。
- time = 3 作为收入节奏：每 3 秒按己方地块数给予资金奖励。
- 点击不可占领或资金不足时显示短暂提示，不中断游戏。

## 7. 卡牌系统

- 每次展示 3 张卡牌。
- CardShowInterval = 2 个节奏单位，约每 12 秒触发一次。
- 弹出卡牌时暂停主循环。
- 选择卡牌后隐藏面板并恢复游戏。
- 卡牌初版包括：箭塔、兵营、龙巢、金币补给。
- 箭塔：在己方地块部署远程塔。
- 兵营：提升附近出兵能力或部署产兵建筑。
- 龙巢：生成强力己方龙单位。
- 金币补给：立即获得资金。

## 8. 建筑与单位

- 建筑 hp = 100，spawnRate = 3 秒。
- 玩家基地和建筑定期生成 PlayerSoldier。
- 敌方基地定期生成 EnemySoldier，后期生成 EnemyDragon。
- PlayerSoldier：hp 40，speed 3，damage 5。
- EnemySoldier：hp 100，speed 4，damage 10。原始分析中的 speed100/dmg100用于广告压迫，Laya 实现中缩放到可读范围。
- Dragon 单位使用更大模型、更高生命和伤害，并带明显颜色区分。

## 9. 交互规则

- 点击地块：占领、选择建塔位置或显示反馈。
- 点击卡牌：应用对应效果。
- 点击 CTA：调用跳转占位逻辑。
- RedirectAfterTouch：记录全局有效触摸次数，达到 5 次后强调 CTA 或触发跳转占位。

## 10. UI 与引导

- 顶部显示倒计时和金币，白字深色描边。
- 开局 1 秒出现教程：“点击相邻地块扩张领地”。
- 卡牌出现时显示：“选择一张卡牌强化防线”。
- 底部 CTA 文案：“立即下载”。
- 结算弹窗文案：胜利“领地守住了！”，失败“敌军压境！完整版继续挑战”。

## 11. 视觉表现

- 使用 3D 低多边形风格。
- 六边形格采用扁平柱体或平面六边形，颜色高对比。
- 玩家单位以绿色/蓝绿色表示，敌方单位以红色表示。
- 基地和建筑使用几何体组合，优先保证可读性。
- 相机固定俯视，不开启动态缩放或自动平移。

## 12. 胜负与 CTA

- 玩家基地被击破时失败。
- 敌方基地被击破或 80 秒内守住核心节奏时胜利。
- 胜负后暂停游戏并展示 ResultPanel。
- CTA 在局末强展示，底部可常驻弱展示。

## 13. 技术范围

- 使用 LayaAir 3.x TypeScript 实现。
- 场景通过指令流搭建，逻辑脚本挂载到对应节点。
- 如资源不足，可使用程序化几何体和 UI 占位完成可运行复刻。
- 后续资源准备阶段可下载或替换士兵、龙、塔和 UI 素材。

## 14. 验收标准

- 项目可运行且无控制台 error。
- 竖屏画面能完整展示 7x10 六边形战场。
- 点击扩张、资金变化、卡牌选择、建塔、出兵和交战均可交互。
- 倒计时、胜负弹窗和 CTA 流程可见。
- 触摸 5 次后的转化提示逻辑可触发。

## 增量变更 v7

- 调整六边形棋盘布局：每个地块的横向间距、奇数行偏移和纵向间距按等距邻接关系计算，保证六个相邻方向的中心距离一致。
- 调整建筑与基地视觉比例：基地运行时对齐到对应六边形格中心并缩小，卡牌生成的塔、兵营和龙巢脚印缩小到单格内部。
- 强化地块颜色表现：地块与程序化建筑使用不受光照影响的材质，提升玩家、敌方、水、熔岩、中立和空洞地块的颜色可读性。

## 增量变更 v8

- 六边形地块改为复合 3D 块体：深色底座负责侧面厚度和彩色顶面负责阵营/地形颜色，增强立体表现。
- 每个地块外圈略大于彩色顶面，形成明显深色分隔线，避免相邻六边形在顶视角下粘连。
- 占领地块时只更新彩色顶面的材质，保留底座边线和立体侧面效果。

## 增量变更 v9

- 移除深色底座方案，六边形地块恢复为单体 3D 柱块，避免出现上下两层边缘错开的观感。
- 地块分隔线改为沿六边形真实顶面边缘绘制的像素线，边线与彩色块体轮廓对齐。
- 保留方块厚度用于立体表现，占领刷新时直接更新单体地块材质，边线独立保留。

## 增量变更 v10

- 在棋盘下方新增水面底板，作为场景底色和六边形战场背景。
- 水面底板使用 `resources/water/water_surface.png` 贴图，并在运行时加载为 3D 材质纹理。
- 水面平面先于六边形地块创建，位置低于地块底部，避免遮挡棋盘和交互判断。

## 增量变更 v11

- 在 Scene3D 层级中新增 `WaterLayer` 节点，用于在编辑器层级面板中明确显示水面层。
- 运行时 `WaterFloor` 不再挂到 `HexBoard` 下，而是挂到 `WaterLayer` 下，便于单独查看、隐藏或调整水面层。
- 脚本保留 `WaterLayer` 兜底创建逻辑：若场景节点缺失，运行时会自动补建，避免水面底板丢失。

## 增量变更 v12

- 开局进入等待首次点击状态：双方默认建筑隐藏，倒计时、收入、卡牌、单位移动、战斗和产兵都不推进。
- 首次点击任意可建造中立方块后，该方块生成己方初始建筑，敌方上方阵地生成敌方初始建筑，游戏正式开始。
- 所有产兵建筑使用独立 CD，CD 圆圈转满一圈后产出 1 个士兵并重置。
- 卡牌暂停和局末结算会冻结所有建筑产兵 CD 与圆圈进度。

## 增量变更 v13

- 镜头表现对齐本轮参考图：主相机改为近乎正上方正交视角，棋盘纵向铺满中部画面，蓝色水面在棋盘两侧和空洞处露出，底部保留 CTA 区域。
- 首次卡牌展示改为开局后 9 秒触发，保证 10 秒内能看到三选一和建塔反馈；后续卡牌仍保持约 12 秒一次。
- 三选一卡牌从箭塔、兵营、金币补给、龙巢四卡池轮换抽取 3 张；金币补给立即增加资金。
- 箭塔从“直接扣敌方基地血量/参与产兵”调整为远程攻击建筑，只攻击范围内敌方单位；兵营和龙巢继续使用独立产兵 CD。
- 建筑补充 `hp = 100` 状态；普通敌兵速度调整为 4，和需求文档中的 Laya 实现数值一致。

## 增量变更 v14

- 镜头进一步对齐参考图：保持稳定正交俯视，使用显式欧拉角朝向棋盘，避免运行时 `lookAt` 异常导致相机停留在默认侧视角。
- 相机正交尺寸从 16.5 调整为 15.6，棋盘在竖屏中更贴近左右边界，同时仍完整显示 7x10 战场和底部 CTA 区域。
- 棋盘画面占比增大后，蓝色水面在两侧和空洞处继续露出。
- 修正脚本挂在 `Scene3D/HexBoard` 下时的场景查找逻辑，确保运行时能找到 `Main Camera` 与 `WaterLayer`，避免初始化中断。

## 增量变更 v15

- 卡牌触发方式改为成功点击解锁地块后立即弹出三选一，不再由开局 9 秒或后续 12 秒定时器自动触发。
- 首次有效点击任意可建造中立地块时，先完成占领和双方初始据点激活，再立即提供一次卡牌选择。
- 后续每次成功解锁新地块都会弹出卡牌选择，卡牌面板仍暂停主循环，选卡后恢复战斗。
