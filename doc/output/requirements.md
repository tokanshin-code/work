# 地块争夺 3D 试玩复刻 - 需求文档

## 1. 项目定位

本项目是 LayaAir 3.x 竖屏 3D 可玩广告，复刻“地块争夺”的核心广告体验。玩家通过“选卡建造 -> 点击金币解锁相邻地块 -> 为新地块选卡建造”的循环扩张领地，依靠建筑出兵和防御塔抵御敌方高压推进，并在 80 秒内完成试玩体验和 CTA 转化引导。

## 2. 玩法目标

- 3 秒内让玩家理解“先选卡建造，再点击金币解锁相邻地块”。
- 10 秒内展示第一次三选一卡牌、建筑生成和金币解锁反馈。
- 中段通过敌方高数值单位制造压力，突出策略选择价值。
- 末段通过倒计时、胜负弹窗和 CTA 引导下载。

## 3. 核心循环

开局 base 绿色地块 -> 三选一选建筑 -> 建筑在 base 地块生成 -> 相邻地块显示金币费用 -> 点击金币地块付费解锁 -> 新地块变绿 -> 为新地块三选一选建筑 -> 刷新下一圈金币地块 -> 建筑出兵/防御塔攻击 -> 单位自动交战 -> 胜负或倒计时结算 -> CTA。

## 4. 场景结构

- Scene3D
  - Main Camera：俯视倾斜相机，约 X = -60 度，展示完整棋盘。
  - Direction Light：主光源。
  - HexBoard：7x10 六边形格容器。
  - Bases：玩家基地和敌方基地。
  - Buildings：部署建筑容器。
  - Units：双方单位容器。
- Scene2D
  - TopHUD：计时器、资金、提示文本。
  - TutorialLayer：开局引导文字和手指提示。
  - CardChoicePanel：三选一卡牌面板，默认隐藏。
  - ResultPanel：胜负结算和 CTA，默认隐藏。
  - CTAButton：底部常驻或局末下载按钮。

## 5. 地图规则

- 地图为 7 列 x 10 行六边形棋盘。
- 玩家基地位于约 (3, 8)，敌方基地位于约 (3, 1)。
- 地块类型包括 player、enemy、neutral、water、lava、void。
- 玩家只能解锁当前焦点绿色地块周围显示金币图标的 neutral 地块。
- 建筑生成后会将自身所在格和周边 6 个可染色地块涂成建筑阵营颜色。
- 士兵行进时会沿路径染色；地块被反复争夺时由最后路过的士兵阵营覆盖，同格存在双方士兵时显示中立灰色，并带短暂防抖避免闪烁。
- 占领消耗 hexCost = 25。
- 初始 money = 20；开局仅使用已有 base 绿色己方地块并直接弹出三选一建筑卡，不额外占领或选择其他初始地块。
- 地块颜色：玩家 #82e03a，敌方 #FF3333，水 #3399FF，熔岩 #FF6600，中立 #c6c4c5。

## 6. 经济与时间

- TimerCount = 80 秒，倒计时显示在顶部。
- money 初始值为 20。
- hexCost = 25。
- time = 3 作为收入节奏：每 3 秒按己方地块数给予资金奖励；金矿建筑额外提供周期性金币。
- 点击不可占领或资金不足时显示短暂提示，不中断游戏。

## 7. 卡牌系统

- 每次展示 3 张卡牌，分别来自防御性建筑、资源类建筑、兵种建筑三类。
- 卡牌不按时间自动触发：开局直接触发一次；之后每次成功解锁新地块后触发一次。
- 弹出卡牌时暂停主循环。
- 选择卡牌后隐藏面板，在对应绿色地块生成建筑并恢复游戏。
- 所有卡牌只产生建筑，卡牌效果通过建筑功能体现，不直接发金币或直接生成士兵。
- 防御性建筑：箭塔，固定原地，自动攻击范围内敌人，不产金币、不产兵。
- 资源类建筑：金矿，按生产间隔产金币，使用圆形进度条显示进度。
- 兵种建筑：枪兵营、弓兵营、骑兵营，按生产间隔生产对应士兵，使用圆形进度条显示进度。

## 8. 建筑与单位

- 建筑 hp = 100，默认生产间隔 spawnRate = 3 秒；资源建筑和各兵营支持单独配置间隔。
- 枪兵：血量高、攻击低、近战攻击。
- 弓兵：血量低、远程攻击。
- 骑兵：移动速度快，血量和攻击中等，近战攻击。
- 敌方基地定期生成敌方近战单位，维持广告压迫节奏。
- 资源/兵种建筑的生产进度使用圆形进度条，以蒙版扇形填充展示增长。
- 敌方开局也会自动从不同兵种建筑中选择一种作为初始建筑，不固定为 base/单一兵营。
- 单位移动速度需保持广告可读性：枪兵和弓兵慢速推进，骑兵只保持相对最快但不应快速穿越多格；敌方单位也同步降速。

## 9. 交互规则

- 点击金币地块：花费金币解锁该相邻地块，使其变为绿色，并弹出三选一建筑卡。
- 点击卡牌：应用对应效果。
- 点击 CTA：调用跳转占位逻辑。
- RedirectAfterTouch：记录全局有效触摸次数，达到 5 次后强调 CTA 或触发跳转占位。

## 10. UI 与引导

- 顶部显示倒计时和金币，白字深色描边。
- 开局 1 秒出现教程：“点击相邻地块扩张领地”。
- 卡牌出现时显示：“选择一张卡牌强化防线”。
- 底部 CTA 文案：“立即下载”。
- 结算弹窗文案：胜利“领地守住了！”，失败“敌军压境！完整版继续挑战”。

## 11. 视觉表现

- 使用 3D 低多边形风格。
- 六边形格采用扁平柱体或平面六边形，颜色高对比。
- 玩家单位以绿色/蓝绿色表示，敌方单位以红色表示。
- 基地和建筑使用几何体组合，优先保证可读性。
- 相机固定俯视，不开启动态缩放或自动平移。

## 12. 胜负与 CTA

- 一方所有建筑血条清空并销毁时，该方失败。
- 80 秒时间结束时，按双方剩余占领地块数量判定胜负；地块数多的一方获胜，平局默认玩家胜。
- 获胜方会将场上所有地块变为己方颜色，并从获胜方 base 方向向外扩散，依次翻转地块并变色。
- 胜负后暂停游戏并展示 ResultPanel。
- CTA 在局末强展示，底部可常驻弱展示。

## 13. 技术范围

- 使用 LayaAir 3.x TypeScript 实现。
- 场景通过指令流搭建，逻辑脚本挂载到对应节点。
- 如资源不足，可使用程序化几何体和 UI 占位完成可运行复刻。
- 后续资源准备阶段可下载或替换士兵、龙、塔和 UI 素材。

## 14. 验收标准

- 项目可运行且无控制台 error。
- 竖屏画面能完整展示 7x10 六边形战场。
- 点击扩张、资金变化、卡牌选择、建塔、出兵和交战均可交互。
- 倒计时、胜负弹窗和 CTA 流程可见。
- 触摸 5 次后的转化提示逻辑可触发。

## 增量变更 v7

- 调整六边形棋盘布局：每个地块的横向间距、奇数行偏移和纵向间距按等距邻接关系计算，保证六个相邻方向的中心距离一致。
- 调整建筑与基地视觉比例：基地运行时对齐到对应六边形格中心并缩小，卡牌生成的塔、兵营和龙巢脚印缩小到单格内部。
- 强化地块颜色表现：地块与程序化建筑使用不受光照影响的材质，提升玩家、敌方、水、熔岩、中立和空洞地块的颜色可读性。

## 增量变更 v8

- 六边形地块改为复合 3D 块体：深色底座负责侧面厚度和彩色顶面负责阵营/地形颜色，增强立体表现。
- 每个地块外圈略大于彩色顶面，形成明显深色分隔线，避免相邻六边形在顶视角下粘连。
- 占领地块时只更新彩色顶面的材质，保留底座边线和立体侧面效果。

## 增量变更 v9

- 移除深色底座方案，六边形地块恢复为单体 3D 柱块，避免出现上下两层边缘错开的观感。
- 地块分隔线改为沿六边形真实顶面边缘绘制的像素线，边线与彩色块体轮廓对齐。
- 保留方块厚度用于立体表现，占领刷新时直接更新单体地块材质，边线独立保留。

## 增量变更 v10

- 在棋盘下方新增水面底板，作为场景底色和六边形战场背景。
- 水面底板使用 `resources/water/water_surface.png` 贴图，并在运行时加载为 3D 材质纹理。
- 水面平面先于六边形地块创建，位置低于地块底部，避免遮挡棋盘和交互判断。

## 增量变更 v11

- 在 Scene3D 层级中新增 `WaterLayer` 节点，用于在编辑器层级面板中明确显示水面层。
- 运行时 `WaterFloor` 不再挂到 `HexBoard` 下，而是挂到 `WaterLayer` 下，便于单独查看、隐藏或调整水面层。
- 脚本保留 `WaterLayer` 兜底创建逻辑：若场景节点缺失，运行时会自动补建，避免水面底板丢失。

## 增量变更 v12

- 开局进入等待首次点击状态：双方默认建筑隐藏，倒计时、收入、卡牌、单位移动、战斗和产兵都不推进。
- 首次点击任意可建造中立方块后，该方块生成己方初始建筑，敌方上方阵地生成敌方初始建筑，游戏正式开始。
- 所有产兵建筑使用独立 CD，CD 圆圈转满一圈后产出 1 个士兵并重置。
- 卡牌暂停和局末结算会冻结所有建筑产兵 CD 与圆圈进度。

## 增量变更 v13

- 镜头表现对齐本轮参考图：主相机改为近乎正上方正交视角，棋盘纵向铺满中部画面，蓝色水面在棋盘两侧和空洞处露出，底部保留 CTA 区域。
- 首次卡牌展示改为开局后 9 秒触发，保证 10 秒内能看到三选一和建塔反馈；后续卡牌仍保持约 12 秒一次。
- 三选一卡牌从箭塔、兵营、金币补给、龙巢四卡池轮换抽取 3 张；金币补给立即增加资金。
- 箭塔从“直接扣敌方基地血量/参与产兵”调整为远程攻击建筑，只攻击范围内敌方单位；兵营和龙巢继续使用独立产兵 CD。
- 建筑补充 `hp = 100` 状态；普通敌兵速度调整为 4，和需求文档中的 Laya 实现数值一致。

## 增量变更 v14

- 镜头进一步对齐参考图：保持稳定正交俯视，使用显式欧拉角朝向棋盘，避免运行时 `lookAt` 异常导致相机停留在默认侧视角。
- 相机正交尺寸从 16.5 调整为 15.6，棋盘在竖屏中更贴近左右边界，同时仍完整显示 7x10 战场和底部 CTA 区域。
- 棋盘画面占比增大后，蓝色水面在两侧和空洞处继续露出。
- 修正脚本挂在 `Scene3D/HexBoard` 下时的场景查找逻辑，确保运行时能找到 `Main Camera` 与 `WaterLayer`，避免初始化中断。

## 增量变更 v15

- 卡牌触发方式改为成功点击解锁地块后立即弹出三选一，不再由开局 9 秒或后续 12 秒定时器自动触发。
- 首次有效点击任意可建造中立地块时，先完成占领和双方初始据点激活，再立即提供一次卡牌选择。
- 后续每次成功解锁新地块都会弹出卡牌选择，卡牌面板仍暂停主循环，选卡后恢复战斗。

## 增量变更 v16

- 修复运行时动态模型加载：建筑/单位加载到的层级资源优先通过预制体工厂创建实例，失败时保留几何兜底，避免模型加载失败后节点变空。
- 箭塔、兵营和龙巢的运行时路径改为本地 GLB 解包后的 `.lh` 层级资源，减少运行时直接实例化 GLB 的兼容风险。
- 主相机改为斜俯视透视镜头，替代近乎正顶视的平面观感，让六边形高度、基地和建筑模型更明显呈现 3D 纵深。

## 增量变更 v17

- 场景层级新增 `DefaultClickableTileMarker`、`InitialBuildSlot` 和 `UnlockCostLayer`，用于在编辑器中明确查看开局可点地格、初始建筑槽位和解锁费用 UI 层。
- 开局默认可点击地格固定为玩家基地相邻的 `(3,7)`：点击其他地格只给出提示；点击该地格后弹出三选一卡牌，选择建筑卡后在初始槽位生成对应建筑。
- 初始建筑及后续占领焦点周边的相邻可解锁地格显示金币需求；金币不足时费用数字显示红色，金币充足时显示黄色。
- 建筑、基地和单位模型缩放加入单格上限，避免模型超出六边形地格；运行时强化环境光和方向光，提升模型材质与光照层次。

## 增量变更 v18

- 建筑、基地和单位的运行高度改为以六边形地块顶面为基准，统一抬高到地块上方，避免模型陷入地块。
- 地块解锁费用改为“金币图标 + 金币数字”的组合 UI，并优先通过相机投影对齐到地格中心，降低斜俯视下的屏幕偏移。
- 常驻 `CTAButton` 开局隐藏，只在结算阶段与 `ResultPanel` 同时出现，避免局内持续遮挡画面。
- 六边形地块增加暗色侧面阴影层，点击解锁时播放短暂翻转反馈，再刷新为玩家占领色。

## 增量变更 v19

- 模型缩放从固定 `.lh` 比例改为加载后按实际包围盒自适应地格 footprint，兼容本地 FBX 与旧 `.lh` 资源的原始单位差异。
- 建筑/地块模型使用地格半径派生的最大占用范围，单位使用更小的占用范围，避免士兵、Boss 或建筑超过地格边界。
- 保留颜色覆盖、地块高度和翻转反馈逻辑，比例适配只在模型实例化成功后对过大模型等比缩小。

## 增量变更 v20

- 增加 `buildingModelScale`、`soldierModelScale`、`bossModelScale`、`tileModelScale` 四个场景脚本参数，允许在 LayaAir Inspector 中直接手动调整建筑、士兵、Boss 和地块模型比例。
- 场景中新增 `EditorAssetSamples` 下的 `BuildingScaleSample`、`SoldierScaleSample`、`BossScaleSample` 可视样例节点，便于在编辑器里观察模型原始比例和手动调整参考。
- 运行时仍会隐藏 `EditorAssetSamples`，避免样例模型影响试玩画面；实际运行模型使用脚本参数作为基础缩放，并保留超格时的包围盒保护。

## 增量变更 v21

- 基地不再使用一体化 prefab，`PlayerBase` 和 `EnemyBase` 改为普通 `Sprite3D` 容器，运行时由 `BaseTileVisual` 地块底座与 `BaseBuildingVisual` 建筑模型组合而成。
- 增加 `baseBuildingPrefabPath` 与 `baseBuildingModelScale`，基地建筑可单独指定资源和缩放。
- 建筑模型比例拆分为 `towerModelScale`、`barracksModelScale`、`dragonNestModelScale`，士兵/Boss 继续使用 `soldierModelScale`、`bossModelScale`，所有主要建筑和单位都能在 Inspector 单独调整。

## 增量变更 v22

- `EditorAssetSamples` 增加 `BuildingSamples` 与 `UnitSamples` 分组，分层展示基地建筑、箭塔、兵营、龙巢、喷火器、士兵和 Boss 等主要模型资源。
- `WaterLayer` 增加 `WaterSurfaceSample` 节点，使水面贴片也能在分层场景中被看见和定位。
- 运行时新增 `hideEditorWaterSample()`，在创建动态 `WaterFloor` 前隐藏编辑器水面样例，避免预览样例和运行时水面重叠。

## 增量变更 v22

- 开局流程改为直接弹出三选一建筑选项卡，地图上预先存在一个空的绿色己方地块，不再要求点击黄色/高亮地块触发选卡。
- 玩家选择卡牌后，所选建筑从开局绿色地块上生成，卡牌面板关闭并进入战斗流程。
- 建筑生成后，相邻可解锁地块显示金币图标和费用；点击对应地块会花费金币并将该地块变为绿色，解锁地块不再重复弹出卡牌。

## 增量变更 v23

- 解锁新地块后立即再次弹出三选一建筑选项卡，玩家可以为新解锁的绿色地块选择建筑内容。
- 新地块的卡牌选择使用刚解锁的地块作为建造位置，不再复用开局的 `InitialBuildSlot`。
- 选卡完成后隐藏卡牌面板，并刷新新地块周围的金币解锁点，形成“解锁地块 -> 选建筑 -> 显示下一圈金币”的循环。

## 增量变更 v24

- 统一核心玩法描述：当前循环为“选卡建造 -> 点击金币解锁 -> 新地块选卡建造”，不再保留周期性卡牌触发口径。
- 点击解锁限制为当前焦点地块周围带金币图标的候选地块，避免点击其他相邻绿地也能扩张。
- 金矿卡定义为立即获得金币并生成金矿建筑；金矿建筑会在周期收入时提供额外金币。

## 增量变更 v25

- 开局初始建造位置改为已有 base 地块 `(3,8)`，不再额外把 `(3,7)` 变为绿色初始地块。
- 开局仍直接弹出三选一建筑卡，但卡牌选择只作用于 base 地块。
- base 建筑生成后，才在 base 周围显示金币解锁候选地块。

## 增量变更 v26

- 建筑逻辑按类别拆分：箭塔为防御建筑，只攻击范围内敌方单位；金矿为资源建筑，按 `resourceRate = 1.5` 周期产出 `goldSupplyAmount = 35` 金币；枪兵营、弓兵营、骑兵营为产兵建筑，按各自冷却生产对应兵种。资源和产兵建筑使用黑色底图、绿色圆环图与 `mask + drawPie` 显示冷却进度，卡牌暂停和结算状态会冻结冷却。

- 单位逻辑按兵种区分：枪兵高血近战低攻击，弓兵低血远程，骑兵速度最快且中等血攻；当前速度保持为枪兵 `1.35`、弓兵 `1.2`、骑兵 `2.0`、敌方单位 `1.6`，避免单位过快穿越多格导致战斗不可读。
