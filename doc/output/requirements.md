# 地块争夺 3D 试玩复刻 - 需求文档

## 1. 项目定位

本项目是 LayaAir 3.x 竖屏 3D 可玩广告，复刻“地块争夺”的核心广告体验。玩家通过点击六边形格扩张领地，周期性选择三选一卡牌部署防御塔，依靠基地与建筑出兵抵御敌方高压推进，并在 80 秒内完成试玩体验和 CTA 转化引导。

## 2. 玩法目标

- 3 秒内让玩家理解“点击相邻地块扩张”。
- 10 秒内展示第一次三选一卡牌和建塔反馈。
- 中段通过敌方高数值单位制造压力，突出策略选择价值。
- 末段通过倒计时、胜负弹窗和 CTA 引导下载。

## 3. 核心循环

观察战场 -> 点击相邻地块 -> 消耗资金占领 -> 周期性三选一卡牌 -> 部署塔/能力 -> 建筑和基地出兵 -> 单位自动交战 -> 更新资金、地块和战局 -> 胜负或倒计时结算 -> CTA。

## 4. 场景结构

- Scene3D
  - Main Camera：俯视倾斜相机，约 X = -60 度，展示完整棋盘。
  - Direction Light：主光源。
  - HexBoard：7x10 六边形格容器。
  - Bases：玩家基地和敌方基地。
  - Buildings：部署建筑容器。
  - Units：双方单位容器。
- Scene2D
  - TopHUD：计时器、资金、提示文本。
  - TutorialLayer：开局引导文字和手指提示。
  - CardChoicePanel：三选一卡牌面板，默认隐藏。
  - ResultPanel：胜负结算和 CTA，默认隐藏。
  - CTAButton：底部常驻或局末下载按钮。

## 5. 地图规则

- 地图为 7 列 x 10 行六边形棋盘。
- 玩家基地位于约 (3, 8)，敌方基地位于约 (3, 1)。
- 地块类型包括 player、enemy、neutral、water、lava、void。
- 玩家只能占领与己方领地相邻的 neutral 地块。
- 占领消耗 hexCost = 25。
- 初始 money = 20，因此开局需要提供一次免费引导占格或快速收入，避免首击无反馈。
- 地块颜色：玩家 #82e03a，敌方 #FF3333，水 #3399FF，熔岩 #FF6600，中立 #c6c4c5。

## 6. 经济与时间

- TimerCount = 80 秒，倒计时显示在顶部。
- money 初始值为 20。
- hexCost = 25。
- time = 3 作为收入节奏：每 3 秒按己方地块数给予资金奖励。
- 点击不可占领或资金不足时显示短暂提示，不中断游戏。

## 7. 卡牌系统

- 每次展示 3 张卡牌。
- CardShowInterval = 2 个节奏单位，约每 12 秒触发一次。
- 弹出卡牌时暂停主循环。
- 选择卡牌后隐藏面板并恢复游戏。
- 卡牌初版包括：箭塔、兵营、龙巢、金币补给。
- 箭塔：在己方地块部署远程塔。
- 兵营：提升附近出兵能力或部署产兵建筑。
- 龙巢：生成强力己方龙单位。
- 金币补给：立即获得资金。

## 8. 建筑与单位

- 建筑 hp = 100，spawnRate = 3 秒。
- 玩家基地和建筑定期生成 PlayerSoldier。
- 敌方基地定期生成 EnemySoldier，后期生成 EnemyDragon。
- PlayerSoldier：hp 40，speed 3，damage 5。
- EnemySoldier：hp 100，speed 4，damage 10。原始分析中的 speed100/dmg100用于广告压迫，Laya 实现中缩放到可读范围。
- Dragon 单位使用更大模型、更高生命和伤害，并带明显颜色区分。

## 9. 交互规则

- 点击地块：占领、选择建塔位置或显示反馈。
- 点击卡牌：应用对应效果。
- 点击 CTA：调用跳转占位逻辑。
- RedirectAfterTouch：记录全局有效触摸次数，达到 5 次后强调 CTA 或触发跳转占位。

## 10. UI 与引导

- 顶部显示倒计时和金币，白字深色描边。
- 开局 1 秒出现教程：“点击相邻地块扩张领地”。
- 卡牌出现时显示：“选择一张卡牌强化防线”。
- 底部 CTA 文案：“立即下载”。
- 结算弹窗文案：胜利“领地守住了！”，失败“敌军压境！完整版继续挑战”。

## 11. 视觉表现

- 使用 3D 低多边形风格。
- 六边形格采用扁平柱体或平面六边形，颜色高对比。
- 玩家单位以绿色/蓝绿色表示，敌方单位以红色表示。
- 基地和建筑使用几何体组合，优先保证可读性。
- 相机固定俯视，不开启动态缩放或自动平移。

## 12. 胜负与 CTA

- 玩家基地被击破时失败。
- 敌方基地被击破或 80 秒内守住核心节奏时胜利。
- 胜负后暂停游戏并展示 ResultPanel。
- CTA 在局末强展示，底部可常驻弱展示。

## 13. 技术范围

- 使用 LayaAir 3.x TypeScript 实现。
- 场景通过指令流搭建，逻辑脚本挂载到对应节点。
- 如资源不足，可使用程序化几何体和 UI 占位完成可运行复刻。
- 后续资源准备阶段可下载或替换士兵、龙、塔和 UI 素材。

## 14. 验收标准

- 项目可运行且无控制台 error。
- 竖屏画面能完整展示 7x10 六边形战场。
- 点击扩张、资金变化、卡牌选择、建塔、出兵和交战均可交互。
- 倒计时、胜负弹窗和 CTA 流程可见。
- 触摸 5 次后的转化提示逻辑可触发。
