# 投射阴影预览设计

## 目标

在当前 3D 试玩场景中增加一个可开关的投射阴影试验，用于观察建筑和单位投影到棋盘/水面后的视觉效果。

## 方案

采用方案 A：只让建筑、单位和已加载模型投射阴影，尽量保留当前地块与 UI 的亮色广告风格。

## 实现边界

- 在 `src/game/HexGameController.ts` 内增加阴影开关与运行时配置。
- `Direction Light` 开启 `Laya.ShadowMode.SoftLow`，设置阴影距离、强度和分辨率。
- 建筑/单位兜底几何体、异步加载模型与六边形地块设置 `castShadow = true`。
- 六边形地块和水面设置 `receiveShadow = true`。
- 去除原有暗色侧面贴片，让侧面明暗主要由低角度方向光产生。
- 地块使用可受光的 BlinnPhong 材质，并提高 albedo 强度以避免棋盘颜色过暗。

## 验证

- 增加源码级回归脚本，检查阴影开关、光源阴影配置、投射/接收设置均存在。
- 运行 TypeScript 编译检查。
- 运行场景资源校验。
- 如运行时截图可用，再通过预览截图人工确认阴影视觉效果。
